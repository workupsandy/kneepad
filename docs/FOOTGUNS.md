# Footgun database

Generated by `tools/gen_docs.py` from `src/kneepad/data/footguns*.toml`. Do not edit by hand.

- 253 rules: 220 pattern rules plus 33 emitted by engine code (rm, find, git, pipe-to-shell, SQL, protected paths).
- Pattern rules name about 569 distinct tools. Each rule is a pattern family, so one rule covers many concrete commands (every `delete`/`destroy`/`terminate` subcommand of a CLI, for example).
- 639 executable `match` examples and 529 `no_match` examples run in the test suite. This page cannot drift from behaviour.

This is a count of rules and verified examples. It is not a count of "commands covered", and a higher number is not automatically a better safety net: every rule is a chance of a false positive.
