# Kneepad blog

Short, practical articles about keeping AI coding agents from breaking things: real shell forms, real incidents,
and how a local guard like Kneepad handles them (and where it does not).

Articles are drafted with AI help and checked against the code before they go up. Every technical claim in a post
can be reproduced with `kneepad check '<command>'` on the version named in the post. If you find a claim that is
wrong, open an issue.
